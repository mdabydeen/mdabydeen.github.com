## Learning Outcomes

- Run predictable sprint and release cadences.
- Use decision logs to reduce ambiguity across teams.
- Coach developers through growth plans tied to delivery outcomes.

## Teaching Method

This course blends case-based discussion with templates and implementation exercises so students can apply each concept to real project settings.
