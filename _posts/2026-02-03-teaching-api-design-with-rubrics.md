Students improve quickly when grading criteria are explicit. For API design, rubrics reduce ambiguity and create better implementation habits.

## Rubric Dimensions

- Endpoint clarity and naming consistency.
- Error model quality.
- Input validation.
- Versioning and compatibility awareness.
- Documentation completeness.

## Classroom Workflow

Start with a weak API example, review it against the rubric, then iterate together. This makes quality criteria concrete and repeatable.
